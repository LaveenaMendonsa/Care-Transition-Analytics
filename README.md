# Care Transition Efficiency & Placement Outcome Analytics

## 📌 Project Overview

This project focuses on analyzing care transition efficiency and placement outcomes using Python, Exploratory Data Analysis (EDA), and Streamlit.

The project aims to identify operational bottlenecks, analyze transfer and discharge efficiency, and visualize trends in care transition processes through an interactive dashboard.

## 🎯 Objectives

- Analyze care transition and placement outcome data.
- Evaluate transfer and discharge efficiency.
- Identify operational bottlenecks.
- Explore reporting trends and outcome stability.
- Develop an interactive dashboard using Streamlit.

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Streamlit

- Transfer Efficiency
- Discharge Effectiveness

These metrics help explore operational performance and reporting trends.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/LaveenaMendonsa/Care-Transition-Analytics.git
```

### 2. Navigate to the project folder

```bash
cd Care-Transition-Analytics
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn streamlit jupyter
```

### 4. Launch the dashboard

```bash
python -m streamlit run app.py
```

The dashboard will open in your browser at:

`http://localhost:8501`
